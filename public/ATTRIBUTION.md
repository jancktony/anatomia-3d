# Atribución y licencias

Esta aplicación es un proyecto educativo independiente y no copia contenido propietario de Anatomy Learning.

## Modelo anatómico integrado

La versión actual utiliza la geometría procesada del proyecto **Human Atlas** de ashemag, cuyo modelo está basado en **BodyParts3D 4.0**.

**Atribución requerida:**

> BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International.

- Fuente de datos: BodyParts3D 4.0 — The Database Center for Life Science (DBCLS).
- Adaptación utilizada: Human Atlas, con geometría preparada para visualización web.
- Licencia de los datos anatómicos: **CC BY 4.0**.
- Código de Human Atlas: MIT.
- Three.js: MIT.

La aplicación conserva esta atribución y no presenta los modelos anatómicos como contenido propietario propio.

## Limitaciones

El modelo integrado corresponde a una referencia anatómica masculina adulta y no representa todas las estructuras, variaciones anatómicas ni todas las condiciones clínicas posibles.

La aplicación tiene finalidad educativa y no constituye una herramienta de diagnóstico, tratamiento o cirugía.

Al crear una distribución local o una aplicación de escritorio, esta atribución debe mantenerse junto con los archivos anatómicos correspondientes.

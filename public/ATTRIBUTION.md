# Atribución y licencias

Esta aplicación se desarrolla como proyecto educativo independiente y no copia contenido propietario de Anatomy Learning.

Para la integración de modelos anatómicos se utilizarán fuentes abiertas con sus licencias correspondientes. Una referencia principal considerada para la capa anatómica es BodyParts3D 4.0, cuya información y adaptaciones abiertas pueden distribuirse bajo CC BY 4.0 según la documentación de su proyecto Human Atlas.

Fuentes de referencia:
- BodyParts3D — The Database Center for Life Science.
- Human Atlas (ashemag/human-atlas) — código MIT y datos anatómicos BodyParts3D bajo CC BY 4.0.
- Three.js — licencia MIT.

Antes de redistribuir cualquier archivo de geometría, debe conservarse la atribución y la licencia específica del conjunto de datos utilizado.

La aplicación es educativa y no constituye una herramienta de diagnóstico.
